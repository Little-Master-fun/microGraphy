/*********************************************************************************************************************
* 目录名称          test
* 功能说明          测试程序目录
* 
* 目录作用说明：
* 本目录用于存放各种硬件模块和功能的测试程序，方便开发者验证硬件功能和调试代码
* 
* 当前包含的测试文件：
* 
* 1. test_sch16tk10.h / test_sch16tk10.c
*    - 功能：SCH16TK10 IMU传感器测试程序
*    - 作用：验证IMU传感器的初始化、数据读取和显示功能
*    - 使用：在main函数中调用test_imu()即可
*    - 显示：通过IPS114屏幕实时显示传感器数据
* 
* 2. test_motor.h / test_motor.c
*    - 功能：双电机驱动系统测试程序
*    - 作用：验证电机驱动的基本功能、速度控制和差速运动
*    - 使用：在main函数中调用test_motor()进行综合测试
*    - 测试项目：
*      ? test_motor_basic(): 基本功能测试（方向控制、启停）
*      ? test_motor_speed(): 速度档位测试（低中高速、正反转）
*      ? test_motor_differential(): 差速运动测试（直行、转弯、原地转向）
*      ? test_motor(): 综合测试（包含所有测试项目）
*    - 显示：通过IPS114屏幕显示测试进度和状态
* 
* 使用说明：
* 1. 在主程序中包含相应的测试头文件
* 2. 调用对应的测试函数
* 3. 确保硬件连接正确
* 4. 编译并下载程序到目标硬件
* 
* 添加新测试程序的建议：
* 1. 创建test_xxx.h和test_xxx.c文件
* 2. 在头文件中声明测试函数
* 3. 在源文件中实现具体的测试逻辑
* 4. 添加详细的文件说明和函数注释
* 5. 更新本README文件
********************************************************************************************************************/
